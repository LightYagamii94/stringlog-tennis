# StringLog Tennis v2

PWA mobile-first per registrare le incordature di due racchette da tennis e le ore di gioco fino alla rottura della corda.

## Novità v2
- Selettore iniziale Racchetta 1 / Racchetta 2
- Ogni racchetta ha la propria incordatura attiva
- Ore, storico, durata media e record separati per racchetta
- Possibilità di rinominare le due racchette
- Migrazione automatica dei dati della v1 sulla Racchetta 1
- Service worker aggiornato per ricevere più facilmente le nuove versioni

## Funzioni
- Nuova incordatura
- Corda, calibro, tensione e note
- Aggiunta sessioni di gioco con ore/minuti
- Chiusura dell'incordatura alla rottura
- Storico e statistiche per racchetta
- Backup e ripristino JSON
- Installabile come PWA
- Funzionamento offline dopo il primo caricamento
