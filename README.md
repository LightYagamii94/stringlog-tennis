# StringLog Tennis

PWA mobile-first per registrare le incordature della racchetta da tennis e le ore di gioco fino alla rottura della corda.

## Funzioni
- Nuova incordatura
- Racchetta, corda, calibro, tensione e note
- Aggiunta delle sessioni di gioco con ore/minuti
- Chiusura dell'incordatura alla rottura
- Storico, durata media e record
- Backup e ripristino JSON
- Installabile come PWA
- Funzionamento offline dopo il primo caricamento

## Importante
Per installare correttamente la PWA, questi file devono essere pubblicati su un hosting HTTPS stabile.
Non aprire semplicemente `index.html` come file locale sul telefono: i browser mobili applicano limitazioni ai file locali e ai service worker.

Hosting consigliati: GitHub Pages, Cloudflare Pages, Netlify o Vercel.
